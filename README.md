# seleniumweb-junit-cucumber-pom
Estructura de trabajo usando lenguaje de programación JAVA, usando MAVEN, JUNIT, CUCUMBER, EXCEL y JSON como fuente de datos, ALLURE como reporting.

- **Build Tool:** Maven
- **Data Source:** Excel y JSON(data-driven testing)

## ▶️ How to Run

### Prerequisites
- Java JDK 17+
- Maven installed

### Steps
```bash
# Clone the repository
git clone https://github.com/mikeai-lab/seleniumweb-junit-cucumber-pom.git

# Navigate to project
cd seleniumweb-junit-cucumber-pom

# go to the folder src/test/resources/features and execute the desired method for each feature
```
